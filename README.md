# Animal Adoption Platform

A full stack web application for managing and listing animals available for adoption. Users can register, browse animals with filters, and submit adoption requests. Administrators manage the entire flow through a dedicated dashboard.

---

## Tech Stack

- **Front-end:** React
- **Back-end:** Node.js, Express
- **Database:** MySQL / MongoDB
- **Authentication:** JWT

---

## Features

- User registration and login with JWT authentication
- Full CRUD for animal listings with image upload
- Filters by species, size, age and breed
- Adoption request submission and status tracking
- Admin dashboard for complete platform management
